## 一、需求审核结果（v0.1 已评审，本节保留存档）

### 1.1 保留的核心需求

| 原始需求 | 结论 | 说明 |
|---|---|---|
| 日历 / 周历 / 月历视图 | ✅ 保留 | 作为**截止日分布预览**（见 v0.2 模型修正，角色降级为辅助视图） |
| 任务待办管理器 | ✅ 保留 | 精简版：只做"关键节点"管理 |
| 任务字段：title / 详情 / 日期 + 倒计时 | ✅ 保留 | 倒计时是灵魂功能 |
| 点击图标弹出任务弹窗 | ✅ 保留 | Chrome Extension Popup，385px |
| 提示工具定位 | ✅ 保留且强化 | 不做番茄钟、不做全功能 todolist |

### 1.2 实现方式修正

- 「管理后台」→ **扩展管理页（Options Page）**：浏览器内全屏页面，零服务器成本
- 数据存储 → `chrome.storage.sync`：免登录，跟随 Google 账号多设备同步

### 1.3 去除 / 降级

- ❌ 账号系统、番茄钟/打卡/统计、多人协作
- ⬇️ 标签体系 → 仅保留一个可选「项目」归属字段

### 1.4 已确认纳入的新增建议

1. 图标角标：常驻显示「挂起中任务数」
2. 倒计时颜色语义：>7 天平静 / 3–7 天琥珀 / <3 天红色脉冲
3. 解压交互：勾选溶解下沉 + 弹簧缓动 `cubic-bezier(0.34, 1.56, 0.64, 1)`

## 二、v0.2 重大设计修正：挂起模型（Pin Model）

### 2.1 评审发现的问题

> 原方案按「日程/日历事件」建模：任务落在截止日那天，过了就翻篇。但工作节点的真实生命周期是——**从创建那天起就该一直挂在眼前，直到完成或手动取消**。用日历管理会导致：过了截止日任务就"消失"，正是 Mac 日历让人遗忘的根因。

### 2.2 修正后的数据模型

```
NodeTask {
  id, title, detail?, project?,
  createdAt,        // 创建即挂起
  dueDate?,         // 截止日（可选；无日期的节点常驻列表底部）
  status: hanging | done | cancelled
}
```

### 2.3 交互规则

| 规则 | 说明 |
|---|---|
| **常驻挂起** | 任务创建后立即进入 Popup 主列表「挂起中」，按紧急度排序（逾期 > <3 天 > 3–7 天 > >7 天 > 无日期） |
| **逾期不消失** | 超过 dueDate 未完成：卡片红色描边 + 左侧红色脉冲条 + 「逾期 N 天」，钉在列表最顶部 |
| **日历降级为预览** | 日/周/月视图只展示截止日的分布密度（标记点），点击某天可筛选查看当日节点；主列表始终是全部挂起任务 |
| **退出方式仅两种** | 勾选完成（溶解归档）/ 管理页手动取消，不存在"过期自动隐藏" |
| **角标语义** | 图标 Badge = 挂起中任务总数；存在逾期任务时 Badge 变红 |

### 2.4 轻量新增编辑器（Popup 内滑出）

为保持「小巧轻便」，不跳页、不弹重型表单，在 Popup 底部弹簧滑出一张玻璃卡片：

- **标题**：单行输入，自动聚焦，必填，40 字上限
- **截止**：快捷芯片「明天 / 3 天后 / 下周」一键填充 + 原生 date 拾取器兜底；可留空（无日期节点常驻底部）
- **项目**：选填，10 字小输入框
- **详情**：选填，2 行 textarea，120 字上限——引导"一句话即可"，防止退化成笔记软件
- 操作：「挂起它」/「取消」；保存后卡片以缩放弹入动画落到列表正确排序位

### 2.5 响应式处理

- Popup 宽固定 385px（Chrome 限制 800px 内），内部全部弹性布局，无响应式风险
- 管理页：`max-width 560px` 内容栏 + 断点适配（≤960px 单栏堆叠，≤480px 月历格子收紧、字号降档）
- 编辑器等小屏控件使用 `flex-wrap`，芯片可换行不溢出

## 三、产品定义（更新版）

**一句话定位**：住在浏览器工具栏上的「工作关键节点提示器」——节点挂起后不走，直到你干掉它。

**功能模块（V1）**

1. **Popup 弹窗**：视图切换（日/周/月，截止日预览）→「挂起中」任务列表 → 底部滑出式新增编辑器 → 管理页入口
2. **管理页**：月历总览、完整 CRUD、逾期改期、归档（done/cancelled）记录
3. **提醒系统**：角标计数 + 倒计时颜色语义 + 逾期钉顶（V1.1 可选桌面通知）
