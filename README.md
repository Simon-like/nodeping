# NodePing ◈

> 住在浏览器工具栏上的「工作关键节点提示器」——节点挂起后不走，直到你干掉它。

NodePing 是一个 Chrome 扩展（Manifest V3），用来对抗"Mac 日历太隐蔽、工作节点转头就忘"的问题。它不是番茄钟、不是全功能 TodoList，只做一件事：**把接下来的关键节点（提测、评审、上线）常驻在你一抬眼就能看到的地方**。

## ✨ 核心设计：挂起模型（Pin Model）

传统日程工具里，任务属于某一天，过期就翻篇——这正是遗忘的根源。NodePing 里任务从创建起就**常驻挂起列表**，只有两种退出方式：勾选完成，或手动取消。

- **逾期不消失**：过期任务红色描边 + 脉冲条，永远钉在列表最顶部
- **倒计时颜色语义**：>7 天平静蓝 / 3–7 天琥珀 / <3 天红色脉冲 / 逾期钉顶
- **图标角标**：工具栏图标常驻显示挂起中任务数，存在逾期时角标变红——不点开也能被提醒

## 🚀 功能

- **Popup 弹窗**（点击图标）：日 / 周 / 月三视图截止日预览 + 挂起列表 + 底部滑出式轻量编辑器
- **点击卡片即编辑**：新增、修改、完成一气呵成
- **相关链接**：任务可挂多条链接，后台自动抓取页面标题（Open Graph / `<title>`），卡片上以「favicon + 标题」胶囊展示，点击直达
- **详情自动链接化**：备注里的 URL 自动高亮可点击
- **管理页**：月历总览、完整 CRUD、逾期改期、归档（完成/取消）恢复与删除
- **统计复盘**：当前挂起、逾期、近 30 天完成率与按期率、最近 8 周节奏、项目分布和复盘建议
- **统一日期选择**：Popup 与管理页共用自绘月历，支持今天、明天、下周和无日期快捷操作
- **存储维护**：同步数据分段保存，显示真实容量；达到 85% 预警，写入失败保留编辑内容并给出提示
- **归档保留策略**：默认自动清理 90 天前的完成 / 取消记录，可调整或关闭；挂起和逾期节点永不自动删除
- **解压交互**：勾选溶解下沉、弹簧缓动（`cubic-bezier(0.34, 1.56, 0.64, 1)`）、列表底部渐隐 + 「还有 N 条」提示胶囊
- **玻璃拟态**：主题 A · 薄雾蓝，backdrop-filter 磨砂质感
- **多端同步**：`chrome.storage.sync` 跟随 Google 账号，零服务器

## 📦 安装

1. Chrome 打开 `chrome://extensions`，右上角开启「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本仓库目录
3. 建议将 NodePing 固定到工具栏（角标才会一直可见）
4. 首次添加链接时，会申请跨域读取权限（仅用于抓取链接标题），允许后即可享受标题预览

## 🛠 技术栈

零构建、零依赖，刻意保持简单：

| 层 | 方案 |
|---|---|
| 平台 | Chrome Extension Manifest V3 |
| 视图 | 原生 HTML / CSS（设计变量 + backdrop-filter） |
| 逻辑 | 原生 ES Modules（Popup / Options / Service Worker） |
| 存储 | `chrome.storage.sync` |
| 后台 | Service Worker：角标维护、定时刷新、链接标题抓取 |
| 权限 | `storage` `alarms` `favicon` + 可选 `host_permissions`（添加链接时动态申请） |

## 📁 目录结构

```
├── manifest.json        # MV3 清单
├── background/sw.js     # 角标 / 定时刷新 / 链接标题抓取
├── popup/               # 工具栏弹窗（385px）
├── options/             # 管理页（月历 + CRUD + 归档）
├── shared/              # 数据层（挂起模型）与 UI 工具
├── icons/               # 扩展图标
├── docs/                # 产品立项报告
├── prototype/           # 交互原型存档
└── tools/               # 图标生成脚本 + 无头浏览器调试脚本
```

## 🔒 隐私

数据只存在你自己的 Chrome Sync 存储里，不经过任何第三方服务器。链接标题抓取由扩展在本机直接完成。
